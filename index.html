PAANO MAGSIMULA

How to install

Paano i-install

1

Tap the download button above

Pindutin ang download button sa itaas

The file (SariSariStoreProductScanner.apk) will save to your phone.

Mase-save ang file (SariSariStoreProductScanner.apk) sa iyong telepono.

2

Allow installs from this source

Payagan ang pag-install mula rito

Android will ask permission since this isn't from the Play Store. Tap "Settings" then turn on "Allow from this source."

Magtatanong ang Android dahil hindi ito galing sa Play Store. Pindutin ang "Settings" pagkatapos i-on ang "Allow from this source."

3

Tap "Install"

Pindutin ang "Install"

Open the downloaded file and confirm the install. It only takes a few seconds.

Buksan ang na-download na file at kumpirmahin ang install. Ilang segundo lang.

4

Open the app and allow camera access

Buksan ang app at payagan ang camera

Needed for scanning barcodes. You're ready to go.

Kailangan ito para sa pag-scan ng barcode. Handa ka na.

GABAY SA PAGGAMIT

How to use each feature

Paano gamitin ang bawat bahagi

1

From the home screen, tap "Add Product"

Sa home screen, pindutin ang "Magdagdag ng Produkto"

2

Point your camera at the item's barcode

Itutok ang camera sa barcode ng produkto

3

Type the product name and price, then tap "Save Price"

I-type ang pangalan at presyo, pagkatapos pindutin ang "I-save ang Presyo"

4

If it's already registered, you'll see its current price and can go manage it instead

Kung naka-rehistro na, makikita ang kasalukuyang presyo at pwede itong pamahalaan

1

From the home screen, tap "Check Price"

Sa home screen, pindutin ang "Tingnan ang Presyo"

2

Scan the item — its name and price appear right away

I-scan ang produkto — lalabas agad ang pangalan at presyo

3

Tap "Scan Again" for the next item, or "Back to Home" when done

Pindutin ang "I-scan Ulit" para sa susunod, o "Bumalik sa Home" kung tapos na

1

From the home screen, tap "View All Products"

Sa home screen, pindutin ang "Lahat ng Produkto"

2

Browse your full list of registered products

Tingnan ang buong listahan ng naka-rehistrong produkto

3

Tap the pencil icon to edit a name or price, or the trash icon to delete it

Pindutin ang pencil icon para i-edit ang pangalan o presyo, o ang trash icon para tanggalin

4

Deleting will ask you to confirm first — it cannot be undone

Magtatanong muna bago tanggalin — hindi na ito maibabalik
