# Sari-Sari Store Product Scanner

A simple, offline-first barcode scanner for sari-sari store owners. Scan a barcode to add a product, check its price, or manage your whole registry — no internet required.

**[⬇ Download the app](https://devpoohtah.github.io/sarisari-app/)**

## Features

- **Add Product** — scan a barcode, enter the name and price once
- **Check Price** — scan any registered item, see its price instantly
- **View All Products** — browse, edit, or delete anything you've registered
- Works fully offline (local SQLite database on-device)
- Available in English and Filipino
- Light and dark mode

## Built with

- [Expo](https://expo.dev) / React Native
- `expo-camera` for barcode scanning
- `expo-sqlite` for local, offline storage

## Installation

This app is distributed directly as an APK (not through the Google Play Store). Visit the [download page](https://devpoohtah.github.io/sarisari-app/) for the download link and step-by-step install instructions.
